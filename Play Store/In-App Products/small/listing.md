# In-app product: Small tip

Play Console copy for the small tip. The tier is sold as two one-time products, and both get the same title, description, icon and price, so the tip jar looks the same before and after the first tip. Paste the per-locale title and description into **Monetize → Products → One-time products** for both ids below.

## Product configuration

| Field | Value |
|---|---|
| **Product IDs** | `tip_small` (record) and `tip_small_repeat` (repeat), from `TipTier.SMALL` in `billing/TipProduct.kt`. Permanent: Play ids cannot be edited or reused after deletion |
| **Type** | One-time product (`ProductType.INAPP`) |
| **Consumable?** | `tip_small` is acknowledged and never consumed, so owning it records that the user has tipped. `tip_small_repeat` is consumed after every purchase, so the tier can be tipped again |
| **Unlocks** | Nothing. A tip is a thank-you, and the descriptions say so |
| **Icon** | `icon.png` (512×512, full-bleed launcher purple `#673AB7`, white heart glyph = `favorite_24px`, the mark on the main screen's support card). `icon-rounded.png` is the rounded fallback. Both are generated by `scripts/generate-iap-icons.sh`, see `../README.md` |
| **Price** | Per region in `../pricing/`: Play's conversion everywhere, cut by purchasing power in low and lower-middle-income regions (`ppp-plan.md`) |
