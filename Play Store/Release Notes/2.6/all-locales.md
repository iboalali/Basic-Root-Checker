# Play Store release notes - 2.6

All locales in one place. Language tags are the Play Console codes. Paste each
block under **Release → Production → … → Release notes** for the matching language.

## en-US (default)
```
Version 2.6:
➕ Four new languages: Dutch, Chinese, Malay and Tamil (nine in total)
🛠️ Animated result icon, with a distinct icon for each result
🛠️ Minimum Android version is now 7.0
🔨 Root is detected correctly on the first check after an earlier grant
🔨 KernelSU and APatch are no longer reported as Magisk
🔨 Update card no longer stuck on downloading (Google Play)
🔨 Many smaller fixes
```
